How to use.
<br>
Copy your install medias to a install folder with each disc as a sub folder or download my archived collection here:
https://archive.org/download/the-sims-games-collection/The%20Sims%202.7z
And unpack it to its own folder.
<br>
Then download this collection of files and put them in the root folder of the installations files.
<br>
Open the "keys_single_discs.reg" file in notepad and insert your own licens keys (it wont work without the keys) and save the file.
<br>
If you downloaded my collection then you have to choose the christmas pack. 
You do that by copying the files from one of the sub folders to the "christmasStuff" folder.
<br>
When all that is done you simply just run the "install.bat" file and it will insert the keys in the registry data base, install the game, all the expansion packs in the correct order, updates the game and lastly copying all the extra The Sims 2 store content to the correct place in the documents folder.
<br>
Have fun playing
