How to use.
<br>
Copy your install medias to a install folder with each disc as a sub folder or download my archived collection here:
https://archive.org/download/the-sims-games-collection/The%20Sims%203.7z
And unpack it to its own folder.
<br>
Then download this collection of files and put them in the root folder of the installations files.
<br>
You will also need the keys for the game and all of the DLCs or ells it wont work
<br>
When all that is done you simply just run the "install.ps1" file and it will install the game and all the expansion packs in the correct order.
